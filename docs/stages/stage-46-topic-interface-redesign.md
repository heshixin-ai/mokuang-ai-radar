# 阶段 46：主题界面重构

## 目标

让主题入口从空旷的分类卡片页变成紧凑、可浏览、与情报首页一致的主题追踪界面。

## 调整内容

- 将主题首页改为编辑型导语、主题数据概览、动态主题条和完整主题卡片。
- 主题卡片补充主题用途说明、已发布事件数量和明确的进入状态。
- 桌面端使用三列满格布局，移动端自动切换为单列卡片。
- 增加轻量进入动画、滚动固定和卡片交互，并尊重系统的减少动态效果设置。
- 主题详情页统一标题、数量概览、返回入口和正文宽度。
- 主题详情默认展示完整历史时间线，避免隐藏筛选器后仍只显示近七天。
- 移除事件详情入口残留的箭头，保持全站按钮与链接风格一致。

## 验证

- 桌面端与移动端均无横向溢出。
- 主题卡片、主题详情与返回入口跳转正常。
- 浏览器控制台无错误或警告，页面请求无失败。
- 全量测试、代码检查、生产构建与页面渲染测试通过。
