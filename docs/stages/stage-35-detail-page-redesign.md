# Stage 35 · 事件详情页重设计

完成日期：2026-08-27

## 目标

- 让跳转后的事件详情页与首页黑白灰视觉保持一致。
- 缩短重复内容，提升标题、正文、影响、行动与证据的信息层级。
- 优化桌面端和移动端阅读体验。

## 实现

- 详情页统一使用白色卡片、黑色重点和浅灰背景，导航与首页一致。
- 顶部增加原始来源日期，移除对用户无价值的“已发布”状态。
- “无直接影响”的角色不再显示，影响等级改为中文标签并采用两列卡片。
- 建议行动改为醒目的黑色行动卡片。
- 按来源合并证据，同一个原文链接只显示一次，其支持的事实集中列出。
- 增加完整页脚、清晰返回入口和移动端专属排版。
- 保留事件级标题、描述以及 Open Graph/X 分享元数据。

## 验证

- 全部自动化测试与生产构建通过。
- 桌面端、移动端视觉与交互回归通过。
- 来源外链、返回列表、事件日期及详情页分享元数据检查通过。
