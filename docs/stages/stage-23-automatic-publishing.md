# Stage 23｜无人值守自动发布

## 目标

让符合安全策略的正式事件无需人工确认即可自动发布，同时从公开文章页移除内部置信度信息。

## 本阶段变更

- 公开事件详情页不再展示模型置信度；来源、证据等级与引用继续保留。
- 自动发布最低置信度由 0.90 调整为 0.80，生产继续使用 `safe` 模式且每轮最多发布 1 条。
- 官方来源、允许的事件类型、无风险标记、聚类无歧义且通过结构与引用门禁的内容由定时任务直接发布。
- 不再设置日常人工审核步骤；未通过任一门禁的内容自动拦截，不进入公开页面。
- 管理员后台继续保留修订、立即发布和撤下入口，仅用于异常处置与回滚。

## 验收

- 单元测试覆盖 0.80 阈值和低于阈值的拦截行为。
- 服务端渲染测试确认公开详情页不包含“置信度”。
- 生产环境配置为 `AUTO_PUBLISH_MODE=safe`、`AUTO_PUBLISH_MIN_CONFIDENCE=0.8`、`AUTO_PUBLISH_BATCH_SIZE=1`。
- 部署后触发一次完整的采集、分析与自动发布工作流，并检查运行汇总。
