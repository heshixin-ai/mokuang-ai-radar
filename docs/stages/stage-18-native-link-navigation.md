# 第 18 阶段技术开发文档｜站内链接可靠跳转

## 阶段目标

- 修复生产环境中事件“查看依据”等站内链接可点击但不跳转的问题。
- 保持现有 URL、详情页、视觉样式和无障碍名称不变。

## 根因

- 详情页路由和事件数据均正常，本地直接访问详情页返回 200。
- 生产点击后没有产生详情页请求，说明客户端路由接管了点击，但未完成导航。
- 问题集中在共用的 `next/link` 封装，而不是事件卡片或 D1 数据。

## 技术处理

- `SiteLink` 改为输出原生 `<a href>`。
- 站内导航改为浏览器完整页面跳转，不再依赖当前托管环境中失效的客户端路由接管。
- 统一修复事件详情、主题、实体、订阅、关于和审核后台等使用 `SiteLink` 的入口。

## 验收标准

- 点击“查看依据”后 URL 进入 `/events/{eventId}`。
- 详情页标题与被点击事件一致，服务器返回 200。
- 返回情报列表、主题、实体、订阅和关于链接仍可正常工作。
- lint、自动化测试、生产构建和真实浏览器点击测试通过。
