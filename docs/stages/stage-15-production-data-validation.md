# Stage 15 · 生产真实数据闭环

## 目标

把线上站点从演示数据切换到真实数据，完成一条“官方来源采集 → DeepSeek 分析 → 人工核验 → 聚类判断 → 正式草稿 → 质量门禁 → 发布 → 前台展示”的生产闭环。

## 生产基线

- 阶段开始时线上 D1 表结构完整，但来源、文档、候选与正式事件均为空。
- 生产环境原先使用 `mock` 模型并关闭自动分析，因此首页持续回退到演示数据。
- 审核后台已经启用 ChatGPT 登录，但没有配置审核员白名单。

## 本阶段完成

- 将生产模型切换为 DeepSeek，安全保存模型密钥，并开启有限自动分析。
- 将站点所有者加入审核员白名单。
- 增加受托管 Secret 控制的审核 API 自动化身份；操作统一记录为 `automation@mokuang.internal`，浏览器人工审核仍使用 ChatGPT 身份与邮箱白名单。
- 针对 Sites 单次请求时限，将生产模型单次超时设为 12 秒并关闭同模型重试，使 Pro 超时后仍能在请求期限内回退到 Flash。
- 修复 Vinext 路由预取的运行时错误，站内链接统一关闭不稳定的 RSC 自动预取，保留正常点击导航。

## 首条生产事件

- 来源：OpenAI News 官方 RSS。
- 采集：发现并保存 50 条官方内容。
- 事件：OpenAI 发布适用于 ChatGPT Work 和 Codex 的 Admin 插件。
- 证据：OpenAI 2026-08-25 官方公告。
- 模型：候选与正式稿均由 DeepSeek 真实模型生成。
- 审核：核对公告中的工作区分析、成员/权限管理、使用限制与管理员操作能力后批准。
- 聚类：未发现同类型已发布事件，确认为新事件。
- 质量：`ready`，无阻断项，官方证据，置信度 90%。
- 发布：已进入线上首页、事件详情、主题与实体数据链路。

## 生产验证

- 首页显示“正式事件持续更新”，不再显示演示数据状态。
- 首页正式事件可以进入对应详情页，详情页保留 OpenAI 官方来源链接。
- `/topics`、`/entities`、`/subscribe`、`/about` 和 `/api/v1/health` 均返回 200。
- 浏览器控制台无错误或警告，无失败请求。
- 自动化测试 37 项通过、1 项跳过；Lint 与生产构建通过。

## 尚未完成的外部观察

- 生产构建产物包含 `*/30 * * * *` Cron，但 2026-08-26 17:00 定时点没有产生 scheduled Worker 日志或 D1 运行记录。Sites 公测文档提示部分后台服务与托管模式暂不支持，因此当前不能宣称无人值守定时更新已经生效；需要接入外部调度器，或迁移到明确支持 Cron Trigger 的运行平台。
- 来源成功率仍需在线连续观察满 7 天。
- 当前仍有 48 条 OpenAI 文档等待有限批量分析；系统不会一次性消耗全部模型额度。
- GPT-5.6 价格候选因属于高风险变化且初次分类不够准确，继续保留在待审核区，没有发布。
- 邮件仍使用 outbox；配置已验证发信域名与 Resend 后才能验收真实收件箱送达率。
