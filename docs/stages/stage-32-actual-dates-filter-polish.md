# Stage 32 · 原始发布时间与筛选器排版

完成日期：2026-08-27

## 目标

- 新闻卡片只展示原始来源发布时间，不使用网站入库或上传时间冒充新闻时间。
- 时间筛选和事件排序统一采用原始来源发布时间。
- 类型、时间筛选器保持等宽、等高，整组居中，选中值居中显示。
- 加载区域只保留“加载更多”按钮，不显示任何剩余条数。

## 实现

- 新增统一的来源时间读取与排序方法，主来源记录为唯一公开时间依据。
- 有限时间范围内不纳入缺少有效来源时间的事件；“全部历史”仍可浏览这些事件。
- 桌面端筛选器独立成居中行；移动端保持双列等宽布局。
- 删除按钮内“再显示 N 条”和按钮下“还有 N 条事件”。

## 验证

- 全部自动化测试通过。
- 生产构建通过。
- 桌面端与移动端浏览器回归通过，未出现横向溢出或控制台错误。
