# Stage 24｜前台栏目精简与详情页重排

## 目标

聚焦情报阅读和主题追踪，移除不再需要的栏目与文章内部记录信息，并改善桌面端和移动端阅读排版。

## 本阶段变更

- 文章详情页移除“事件记录”侧栏，正文改为居中的单栏阅读布局。
- 顶部导航只保留“情报”“主题”和“订阅日报”。
- 移除实体栏目、处理流程栏目和关于栏目，同时从 Sitemap、首页预览和页脚清理入口。
- 首页保留独立订阅行动区，让信息流结束后仍有明确下一步。
- 旧的 `/entities`、`/entities/:slug` 与 `/about` 页面不再公开提供。

## 验收

- 桌面与移动端详情页没有“事件记录”，正文宽度与段落层级正常。
- 首页和全站导航不包含实体、处理流程、关于入口。
- `/entities` 与 `/about` 返回 404。
- 单元测试、渲染测试、Lint、生产构建和浏览器检查通过。
