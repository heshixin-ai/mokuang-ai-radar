# 阶段 48：主题页滚动与排版修复

## 目标

解决主题页滚动时标题区与主题选择区重叠、首屏留白偏多以及移动端初始内容短暂不可见的问题。

## 调整内容

- 移除主题导语的无占位固定滚动，让后续内容按正常文档流排列。
- 收紧桌面端导语区、主题选择区和页面底部的垂直间距。
- 移除标题与卡片的非必要入场脚本，避免页面打开时出现短暂空白或发灰。
- 保留主题卡片的深色悬停反馈与跳转能力。
- 清理项目中已无使用场景的 GSAP 依赖。

## 验证

- 1440px 桌面视口滚动后，导语区与主题选择区无重叠。
- 390px 移动视口标题、概览和卡片正常显示，无水平溢出。
- 卡片悬停后背景和文字颜色正常切换。
- 浏览器控制台无错误或警告。
- 代码检查、全量测试与生产构建通过。
