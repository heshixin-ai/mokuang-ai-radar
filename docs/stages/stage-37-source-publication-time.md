# 阶段 37：统一使用来源实际发布时间

## 目标

所有面向读者的新闻时间和日报筛选都使用新闻来源提供的实际发布时间，不使用事件在模况网站上的上传或发布时间。

## 实现

- 首页事件列表、时间筛选和文章详情继续统一读取首要来源的 `publishedAt`。
- 日报事件筛选改为读取首要来源的 `publishedAt`，并按 Asia/Shanghai 自然日判断。
- 来源时间缺失时不回退到网站发布时间，避免把旧新闻误判为当天新闻。

## 验证

- 覆盖“网站今天发布、来源昨天发布”的事件，不进入今天日报。
- 覆盖“网站昨天发布、来源今天发布”的事件，进入今天日报。
- 覆盖来源时间缺失，不使用网站发布时间兜底。
