# 第 1 阶段技术开发文档｜核心情报纵向切片

> 配套文档：`mokuang-prd.html`、《AI 产品 Vibe Coding 通用技术栈手册》与《技术适配声明》。本文档只覆盖第 1 阶段。

## 一、阶段目标

- 交付范围：用代表性样例来源跑通抽取、合并、核验和浏览一条完整链路。
- 阶段产物：事件信息流、事件详情、来源与证据展示、最小 API、版本化 Prompt 和离线测试。
- 验收标准：页面能解释“发生了什么、影响谁、建议做什么、依据是什么”；来源不超过两次点击；桌面和 390px 手机端无页面溢出；刷新后样例数据仍可用。
- 明确不做：真实网络抓取、用户登录、邮件发送、付费、生产自动发布、完整后台管理。
- 主链路：读取受控样例来源 → 生成结构化候选 → 去重/合并 → 返回事件列表与详情 → 人工查看引用。

## 二、技术适配摘要

- 采用全栈 TypeScript 纵向切片，复用同一领域类型。
- 启用平台持久化数据库的逻辑绑定；本地开发可使用受控样例仓库回退，不能保存用户账户等正式数据。
- 模型层使用接口 + mock；真实模型待 Key 与评测集就绪后接入。

## 三、技术栈与模型

- Vinext/Next.js 兼容 App Router、React、TypeScript、Tailwind CSS。
- Zod：API 与模型输出结构校验。
- Vitest：领域逻辑和错误路径测试。
- Playwright：关键浏览路径、响应式与可访问性检查。
- 模型：本阶段为 `mock-v1`，不计入真实模型验收。

## 四、环境与配置

- 本地端口：由开发服务自动选择未占用端口，避免干扰已有 3000/8000 服务。
- `.env.example` 只声明未来需要的模型配置，不含真实值。
- 第一阶段不要求用户提供 Key。

## 五、项目结构

- `app/`：页面与服务端 API。
- `lib/domain/`：事件、来源、引用与状态的领域类型和规则。
- `lib/ai/`：模型适配接口、mock 与 Prompt 版本。
- `lib/repository/`：事件读取接口和样例回退。
- `tests/`：领域和 API 契约测试。

## 六、数据、资产与状态

- Source：`id`、发布方、类型、URL、发布时间和健康状态。
- Event：`id`、类型、标题、变化、影响、建议、证据等级、置信度和审核状态。
- Citation：事件事实与 Source 的可追溯关系。
- 状态：`candidate → needs_review | published | rejected`；第一阶段展示 `published` 与 `needs_review`。
- 样例数据为版本化种子，不伪装成实时新闻。

## 七、API / 工具设计

- `GET /api/v1/events`：返回事件摘要列表；支持主题和状态过滤。
- `GET /api/v1/events/:id`：返回事件、影响、来源与引用；不存在返回统一 404。
- `POST /api/v1/pipeline/preview`：对受控输入运行 mock 抽取与合并，返回结构化预览，不外发、不发布。
- 错误格式：`{"error":{"code":"...","message":"...","requestId":"..."}}`。

## 八、Prompt 设计

- `G-01`：证据边界、提示词注入防护、引用和 JSON 输出纪律。
- `P-01`：事件抽取与标准化。
- `P-02`：跨来源聚类与合并。
- 第一阶段不调用 P-03/P-04 的真实模型，但界面使用等价结构化样例检验字段价值。

## 九、验收界面

- 这是正式产品的第一条纵向切片，不是一次性 Swagger 替代品。
- 首页提供事件信息流、筛选和“为什么重要”；详情页提供前后变化、角色影响、建议行动和逐条来源。
- 提供明确的“演示数据”标识，避免误认为自动实时抓取已上线。

## 十、测试要求

- mock 自动化：Schema、去重、冲突转人工审核、无来源不发布、统一错误。
- 浏览器：桌面与 390px 手机、信息流到详情、筛选、引用链接、404、键盘与 console。
- 真实冒烟：本阶段因无 Key 待验；后续接入模型时用同一输入补测。

## 十一、验收清单

- [ ] 打开首页，能在 10 秒内理解模况解决什么问题。
- [ ] 能按“模型 / API / 价格 / 政策 / 研究”筛选事件。
- [ ] 点击事件后能看到变化、影响对象、建议和来源。
- [ ] 能分辨官方、交叉验证、媒体报道和线索四种证据等级。
- [ ] 手机宽度下内容可读且不出现页面横向滚动。
- [ ] 页面明确显示当前是样例数据，而不是实时新闻。

## 十二、风险与待确认项

- mock 只能验证工程契约，不能证明模型质量。
- 样例来源不代表已完成抓取授权审查。
- 自动发布阈值仍是临时可配置规则。
- 必须由产品经理决定的问题：无。

## 十三、交接给下一阶段

- 下一阶段复用 Event/Source/Citation 契约、Prompt 版本和信息流组件。
- 第一阶段通过后，补充真实来源接入、任务状态与人工审核队列。
