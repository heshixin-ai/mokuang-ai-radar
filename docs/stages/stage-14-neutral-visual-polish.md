# Stage 14 · 首页中性视觉优化

## 目标

根据线上首页的实际观感，重新整理首屏标题的层级与留白，并移除页面中的荧光黄色，让视觉更克制、更适合长期承载 AI 情报内容。

## 本阶段完成

- 将首屏标题固定为两行结构，收窄最大宽度、降低桌面端字号并重新平衡上下留白。
- 移除“发生的变化”的黄色背景与句末标点，改用字重建立层级。
- 移除首页品牌标、按钮箭头、工作台预览、价值卡、事件编号、流程编号和页脚中的黄色。
- 将主要强调统一为黑白灰；“官方来源”保留低饱和浅绿色，用于表达证据状态而不是装饰。
- 移除原生 `mark` 元素，避免浏览器默认黄色样式回退。

## 浏览器验证

- 1600px 桌面、740px 平板和 390px 手机均正常显示。
- 三种尺寸下页面横向溢出均为 0。
- 三种尺寸下未发现黄色前景、背景、边框、阴影或装饰色。
- 页面请求均返回 200，没有控制台警告、错误或失败请求。
