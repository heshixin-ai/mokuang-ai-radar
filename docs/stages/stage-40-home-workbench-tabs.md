# Stage 40：首页工作台切换

## 目标

把首页情报台左侧导航从装饰链接改为清晰的页内内容切换。

## 实现

- 移除“今日情报”右侧事件数字。
- 移除“主题追踪”右侧箭头。
- “今日情报”和“主题追踪”改为可访问的页内标签按钮。
- 当前标签使用黑底，切换时内容标题和列表同步更新。
- 主题追踪展示事件数量最多的前三个主题，可进入对应主题时间线。
- 移动端保留两个横向标签，不再隐藏切换入口。

## 验证

- 服务端渲染测试确认默认选中状态和精简后的标签文本。
- 浏览器验证桌面端与移动端点击切换、黑底状态、前三条主题和控制台输出。
- 运行完整测试、Lint 和生产构建后发布。
